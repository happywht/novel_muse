## 交互流程

```
用户生成场景
     ↓
AI提取状态变更 (带置信度)
     ↓
显示EchoSummaryCard
     ↓
     ├─ 高置信度 (≥0.85) → 自动标记为可查看
     │                      ↓
     │                   用户确认或忽略
     │
     ├─ 中置信度 (0.5-0.85) → 需要审核
     │                         ↓
     │                      用户查看证据
     │                         ↓
     │                   采纳或拒绝
     │
     └─ 低置信度 (<0.5) → 默认折叠
                            ↓
                         可展开查看
                            ↓
                         手动处理
```

## 图标说明

- 🔮 命运回响 - Echo系统标识
- 📊 统计 - 数据分析
- ✅ 高置信度 - 可靠的提取
- ⚠️ 待确认 - 需要审核
- 🚫 低置信度 - 不太可靠
- ⚡ 蝴蝶效应 - 预演影响
- 👁 查看全部 - 跳转到审核面板
- ✓ 采纳 - 确认接受
- ✗ 忽略 - 拒绝
- ☐ 选择 - 批量操作

## 动画效果

```
展开/折叠: animate-fade-in
悬停效果: hover:shadow-lg, hover:border-{color}-500/50
过渡效果: transition-all (300ms), transition-colors (200ms)
进度条: transition-all (500ms ease-out)
```

## 响应式设计

```
桌面端 (>1024px):
- EchoSummaryCard: 全宽
- EchoReviewPanel: 侧边栏 (1/3宽度)

平板端 (768px-1024px):
- EchoSummaryCard: 全宽
- EchoReviewPanel: 模态框

移动端 (<768px):
- EchoSummaryCard: 紧凑模式
- EchoReviewPanel: 全屏模态
```
