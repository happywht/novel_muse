# 项目深度评估报告

## 评估目标

对"Muse: 小说架构师"项目进行全面技术评估，识别P0级严重问题、审查功能模块完备性、评估架构集成质量。

## 评估范围

- **前端代码**: 35个React组件，13个服务模块
- **后端代码**: 2个主路由 + 6个图服务
- **数据层**: MySQL + Neo4j + IndexedDB三存储架构
- **AI集成**: Gemini/GLM多模型路由系统
- **核心功能**: 世界观构建、角色管理、剧情编织、草稿撰写、知识图谱

## 评估维度

1. **代码质量**: P0级严重问题识别
2. **功能完备性**: 模块实现完整性审查
3. **架构集成**: 模块联动性与设计统一性评估

# 技术评估报告

## 一、P0级严重问题清单

### 🔴 问题1: 安全漏洞 - XSS攻击风险

**风险等级**: P0 (紧急)
**位置**: `components/MarkdownRenderer.tsx:10`
**问题代码**:

```
if (content.trim().startsWith('<p>') || content.trim().startsWith('<h')) {
  return <div dangerouslySetInnerHTML={{ __html: content }} />;
}
```

**风险描述**:

- 直接使用`dangerouslySetInnerHTML`渲染用户输入内容
- 没有任何HTML转义或DOMPurify消毒
- AI生成的内容可能包含恶意脚本
- 攻击者可通过精心构造的输入执行任意JavaScript

**修复建议**:

```
import DOMPurify from 'dompurify';

const sanitizedContent = DOMPurify.sanitize(content);
return <div dangerouslySetInnerHTML={{ __html: sanitizedContent }} />;
```

### 🟠 问题8: 数据结构不一致 - ID生成策略混乱

**风险等级**: P0 (严重)
**影响**: 数据关联可靠性

**问题**:

1. **多种ID生成方式并存**:


2. **ID类型不一致**:

- Character ID: `Date.now()` (数字字符串)
- WorldSetting ID: `Date.now()` (数字字符串)

- Chapter ID: 后端UUID / 前端Date.now()

**风险**:

**实现**: `types.ts` (6.3KB, 220+接口)
**优势**:

```typescript
model Character {
    id          String @id
    name        String
    description String @db.Text
    physicalStatus String?
    foreshadowingHooks String[] @default([])

// Neo4j节点映射
CREATE (c:Character {
    id: $id,
    name: $name,
    description: $description,
    physicalStatus: $physicalStatus,
    foreshadowingHooks: $foreshadowingHooks
```

### ⚠️ 架构集成问题

#### 1. **循环依赖风险**

**问题**: `services/gemini/core.ts` 导入 `useProjectStore`

```typescript

// store/useProjectStore.ts 又通过API调用gemini服务
// 潜在循环：store → api → gemini → store
```

**风险**:

- 打包时可能出现模块初始化顺序问题
- 增加代码耦合度
- 单元测试困难（需要Mock整个链）

---

#### 2. **状态管理粒度过粗**

**问题**: 全量ProjectState更新

```typescript
// 任何字段修改触发全量更新
updateProject({ characters: updatedChars });
// → 导致所有useProjectStore订阅者重渲染

// 应使用Zustand切片优化
const useCharacters = create((set) => ({ ... }));
const useChapters = create((set) => ({ ... }));
```

**性能影响**:

- 输入框输入时整个页面闪烁
- 大型项目(100+章节)编辑延迟>500ms

---

#### 3. **错误边界缺失**

**问题**: 无React Error Boundary
**影响**:

- 任何组件错误导致整个应用白屏
- 用户数据可能丢失
- 无法优雅降级

**应添加**:

```
<ErrorBoundary fallback={<DashboardSkeleton />}>
  <PlotWeaver />
</ErrorBoundary>
```

---

#### 4. **知识图谱同步延迟**

**问题**: Neo4j同步为异步，无强一致性保证

```typescript
// store/useProjectStore.ts:339
syncToBackend: async () => {
  try {
    await syncProject(currentProject);
    // ❌ 缺失：未等待Neo4j同步完成
  } catch (err) {
    console.warn('Backend sync failed:', err);
  }
};
```

**导致**:

- 刚保存的数据，知识图谱查询不到
- 状态变更建议基于过时图谱
- 用户体验不一致
