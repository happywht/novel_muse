## 🎯 技术实现详情

### VirtualList组件特性

```typescript
// components/VirtualList.tsx

interface VirtualListProps<T> {
  items: T[]; // 数据列表
  itemHeight: number; // 单项高度
  height: number; // 容器高度
  renderItem: (item: T, index: number) => React.ReactNode; // 渲染函数
  className?: string; // 样式类
}
```

**核心特性**:

1. **自动检测react-window**: 如果已安装则使用原生实现
2. **降级模式**: 未安装时使用普通渲染，保证兼容性
3. **高度自适应**: 根据window.innerHeight动态计算
4. **事件冒泡阻止**: 防止与父级滚动冲突

### 应用模式

**优化前**:

```typescript
{items.map(item => (
  <div key={item.id}>...</div>  // 所有项都渲染，包括视口外的
))}
```

**优化后**:

```typescript
<VirtualList
  items={items}
  itemHeight={80}
  height={window.innerHeight - 400}
  renderItem={(item) => <ItemCard {...item} />}
/>
// 只渲染视口内的~10个项
```

## 🎓 经验总结

### 最佳实践

1. **何时使用VirtualList**:
   - 列表项 > 20个
   - 每项高度固定或可知
   - 性能瓶颈明显

2. **itemHeight设置**:
   - 精确测量实际高度
   - 包含margin/padding
   - 保持一致性

3. **容器高度**:
   - 动态计算（window.innerHeight - offset）
   - 考虑header/footer高度
   - 设置min-height

### 注意事项

1. **避免嵌套滚动**: 虚拟滚动区域内避免overflow-y
2. **事件处理**: 确保onClick/onScroll正常工作
3. **状态管理**: 保持状态在组件外部（如Zustand）
