# 批量操作历史数据库持久化实施报告

## 任务概述

将批量操作历史（batchOperationHistory）从内存存储改为数据库持久化，解决服务器重启后历史记录丢失的问题。

## 修改内容

### 1. 数据库 Schema 更新

**文件**: `server/prisma/schema.prisma`

新增 `BatchOperation` 模型：

```prisma
model BatchOperation {
  id          String   @id @default(cuid())
  projectId   String
  project     Project  @relation(fields: [projectId], references: [id], onDelete: Cascade)
  operation   String   // BATCH_ACCEPT, BATCH_REJECT
  echoIds     String   @db.Text // JSON array
  previousStates String @db.Text // JSON object: { echoId: previousStatus }
  timestamp   BigInt
  expiresAt   BigInt?  // 过期时间，用于清理

  @@index([projectId])
  @@index([expiresAt])
}
```

在 `Project` 模型中添加关系：

```prisma
model Project {
  // ... 现有字段 ...
  batchOperations  BatchOperation[]
}
```

#### 2.2 新增数据库操作函数

**保存批量操作**：

```typescript
const saveBatchOperation = async (projectId: string, operation: BatchOperationRecord) => {
  await prisma.batchOperation.create({
    data: {
      id: operation.id,
      projectId,
      operation: operation.operation,
      echoIds: JSON.stringify(operation.echoIds),
      previousStates: JSON.stringify(operation.previousStates),
      timestamp: BigInt(operation.timestamp),
      expiresAt: BigInt(Date.now() + 5 * 60 * 1000), // 5分钟过期
    },
  });
};
```

**获取最近的批量操作**：

```typescript
const getRecentBatchOperation = async (projectId: string, operationId?: string) => {
  const fiveMinutesAgo = BigInt(Date.now() - 5 * 60 * 1000);

  if (operationId) {
    return await prisma.batchOperation.findFirst({
      where: {
        id: operationId,
        projectId,
        timestamp: { gte: fiveMinutesAgo },
      },
    });
  }

  return await prisma.batchOperation.findFirst({
    where: {
      projectId,
      timestamp: { gte: fiveMinutesAgo },
    },
    orderBy: { timestamp: 'desc' },
  });
};
```

**获取批量操作历史列表**：

```typescript
const getBatchOperationHistory = async (projectId: string) => {
  const fiveMinutesAgo = BigInt(Date.now() - 5 * 60 * 1000);

  return await prisma.batchOperation.findMany({
    where: {
      projectId,
      timestamp: { gte: fiveMinutesAgo },
    },
    orderBy: { timestamp: 'desc' },
  });
};
```

**删除批量操作记录**：

```typescript
const deleteBatchOperation = async (operationId: string) => {
  await prisma.batchOperation.delete({
    where: { id: operationId },
  });
};
```

**清理过期记录**：

```typescript
const cleanupExpiredOperations = async () => {
  try {
    const result = await prisma.batchOperation.deleteMany({
      where: {
        expiresAt: { lt: BigInt(Date.now()) },
      },
    });
    if (result.count > 0) {
      console.log(`Cleaned up ${result.count} expired batch operations`);
    }
  } catch (err) {
    console.error('Failed to cleanup expired operations:', err);
  }
};

// 启动定期清理任务（每5分钟执行一次）
setInterval(cleanupExpiredOperations, 5 * 60 * 1000);
```

#### 2.3 修改 API 端点

**POST /api/projects/:id/echoes/batch-accept**

- 将 `previousStates` 从 `Map<string, string>` 改为 `Record<string, string>`
- 使用 `saveBatchOperation()` 保存到数据库

**POST /api/projects/:id/echoes/batch-reject**

- 将 `previousStates` 从 `Map<string, string>` 改为 `Record<string, string>`
- 使用 `saveBatchOperation()` 保存到数据库

- 使用 `getRecentBatchOperation()` 从数据库获取操作

**GET /api/projects/:id/echoes/batch-history**

- 使用 `getBatchOperationHistory()` 从数据库获取历史

## 注意事项

1. **BigInt 处理**：timestamp 和 expiresAt 使用 BigInt 类型，需要在查询时使用 `BigInt()` 转换
2. **JSON 序列化**：echoIds 和 previousStates 存储为 JSON 字符串，需要使用 `JSON.parse()` 和 `JSON.stringify()` 处理
3. **过期时间**：批量操作默认5分钟后过期，可通过修改 `expiresAt` 计算逻辑调整
4. **清理频率**：定期清理任务每5分钟执行一次，可根据需要调整 `setInterval` 间隔

## 后续优化建议

2. **批量查询优化**：如果历史记录数量较大，可考虑分页查询
