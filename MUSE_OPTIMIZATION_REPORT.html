核心痛点分析

1. 类型安全缺失 (严重)

apiService.ts 等关键文件大量使用 any 类型，失去 TypeScript 保护

export const fetchProject = async (id: string): Promise<any>

修复: 定义 ProjectDTO 接口，替换所有 any

2. 硬编码配置 (严重)

API 地址、数据库连接串等硬编码，无法跨环境部署

API_BASE = 'http://localhost:3001/api'

修复: 使用 VITE_ 前缀环境变量

3. Store 过于庞大 (897行)

单一 Store 承载所有状态，缺少 selector 模式导致过度渲染

修复: 按功能拆分 Store，使用 zustand/selectors

4. 可访问性缺失

Sidebar 键盘不可用，缺少 ARIA 标签，模态框无焦点陷阱

修复: 添加键盘事件、语义化标签、焦点管理

5. 测试覆盖率低 (约15%)

Store、API 服务、AI 服务等核心模块缺少单元测试

修复: 添加 Vitest + Testing Library，目标覆盖率 70%+

6. 性能优化空间

配置未缓存、组件缺少 memoization、后端检测延迟

修复: 添加 React.memo、配置缓存、骨架屏加载
