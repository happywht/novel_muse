## 方案一：角色创建深度字段提取 (2.1-1)

### 1.1 问题根因

**当前实现** (`CharacterCreatorContext.tsx:181-211`):
```typescript
const handleGenerateChar = useCallback(async () => {
    const prompt = `为一部类型为 "${project.genre}" 的小说创建一个详细的角色档案...`;
    const description = await generateText(prompt, 'character_gen', project.creativeSettings);
    // ❌ 只获取 description，没有获取深度字段
}, [...]);
```

**一键创世纪实现** (`world.ts:batchGenerateCharacters`):
```typescript
// ✅ 使用完整 JSON Schema，获取所有字段
const characterSchema = {
    properties: {
        name, role, archetype, description,
        alignment, desire, fear, signature, contrast, weakness,
        relationships, structuredRelations
    }
};
```

### 1.2 修复方案

**方案A（推荐）**：复用 `batchGenerateCharacters` 的核心逻辑

1. 提取 `batchGenerateCharacters` 中的 Schema 和 Prompt 为独立函数
2. 创建 `generateSingleCharacter()` 函数
3. 修改 `handleGenerateChar` 调用新函数

**方案B**：修改现有 `handleGenerateChar`

直接在 `handleGenerateChar` 中使用 `generateWithSchema` 替代 `generateText`

### 1.3 代码修改清单

| 文件 | 修改内容 |

| `services/gemini/world.ts` | 提取 `getCharacterSchema()` 和 `getCharacterPrompt()` |
| `services/gemini/world.ts` | 新增 `generateSingleCharacter()` 函数 |
| `components/CharacterCreator/CharacterCreatorContext.tsx` | 修改 `handleGenerateChar` 使用新函数 |
| `services/gemini/writing.ts` | 可选：添加 `generateCharacterWithSchema()` |

### 1.4 预期效果

- 手动创建：基础字段 + 空的深度字段（待用户填充）

## 方案二：角色深度字段编辑 (2.1-2)

### 2.1 问题根因

**当前编辑界面** (`CharacterDetail.tsx:593-639`):
```tsx
{/* 只读展示，无编辑功能 */}
{activeChar.desire && (
    <div className="...">
        <span className="text-muted">核心欲望</span>
        <span>{activeChar.desire}</span>
    </div>
)}
```

**当前保存逻辑** (`CharacterCreatorContext.tsx:289-297`):
```typescript
const handleSaveEdit = useCallback(() => {
    const updatedChars = project.characters.map((c) =>
        c.id === activeChar.id ? { ...c, description: editDescription } : c
        // ❌ 只保存 description
    );
}, [...]);
```

### 2.2 修复方案

#### Step 1: 添加编辑状态变量

```typescript
// CharacterCreatorContext.tsx
const [editDesire, setEditDesire] = useState('');
const [editFear, setEditFear] = useState('');
const [editSignature, setEditSignature] = useState('');
const [editContrast, setEditContrast] = useState('');
const [editWeakness, setEditWeakness] = useState('');
```

#### Step 2: 修改编辑入口

```typescript
const startEditing = useCallback(() => {
    setEditDescription(activeChar.description || '');
    setEditDesire(activeChar.desire || '');
    setEditFear(activeChar.fear || '');
    setEditSignature(activeChar.signature || '');
    setEditContrast(activeChar.contrast || '');
    setEditWeakness(activeChar.weakness || '');
    setIsEditing(true);
}, [activeChar]);
```

#### Step 3: 修改保存逻辑

```typescript
const handleSaveEdit = useCallback(() => {
    const updatedChars = project.characters.map((c) =>
        c.id === activeChar.id ? {
            ...c,
            description: editDescription,
            desire: editDesire,
            fear: editFear,
            signature: editSignature,
            contrast: editContrast,
            weakness: editWeakness,
        } : c
    );
    updateProject({ characters: updatedChars });
    setIsEditing(false);
    toast.success('档案更新已保存');
}, [activeChar, editDescription, editDesire, editFear, editSignature, editContrast, editWeakness, ...]);
```

#### Step 4: 修改 UI 组件

在 `CharacterDetail.tsx` 中为每个深度字段添加编辑模式：

```tsx
{isEditing ? (
    <textarea
        value={editDesire}
        onChange={(e) => setEditDesire(e.target.value)}
        placeholder="核心欲望..."
    />
) : (
    <span>{activeChar.desire || '未设置'}</span>
)}
```

| `components/CharacterCreator/CharacterDetail.tsx` | 为深度字段添加编辑控件 |

## 方案三：情节生成字段保留 (3.2-1)

### 3.1 问题根因

**当前代码** (`hooks/usePlotWeaverAI.ts:48-55`):
```typescript
const newNodes: PlotNode[] = result.map((node, idx) => ({
    id: crypto.randomUUID(),
    title: node.title,
    content: node.content,
    order: idx,
    relatedCharacters: [],     // ❌ 硬编码为空数组
    relatedLocations: []       // ❌ 硬编码为空数组
    // beatTag 缺失
    // conflictScenario 缺失
}));
```

### 3.2 修复方案

**直接修复**（低风险，高收益）：

```typescript
const newNodes: PlotNode[] = result.map((node, idx) => ({
    id: crypto.randomUUID(),
    title: node.title,
    content: node.content,
    order: idx,
    // ✅ 保留 AI 返回的字段
    beatTag: node.beatTag || 'OTHER',
    relatedCharacters: node.relatedCharacters || [],
    relatedLocations: node.relatedLocations || [],
    relatedChapters: node.relatedChapters || [],
    conflictScenario: node.conflictScenario || null,
}));
```

### 3.3 代码修改清单

| 文件 | 修改内容 |
|------|----------|
| `hooks/usePlotWeaverAI.ts` | 修改 `performGeneratePlot` 函数，保留所有 AI 返回字段 |

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 角色生成 API 变更 | 可能影响现有数据 | 新字段设为 optional，向后兼容 |
| UI 布局变更 | 可能影响用户体验 | 保持原有展示逻辑，仅在编辑模式下显示新控件 |
| 数据迁移 | 旧角色缺少深度字段 | 提供默认值，不强制填充 |
