# TemplatePreview 组件实现总结

## 宼概述
已成功创建 `TemplatePreview.tsx` 组件，用于实时预览合并后的模板效果。

## 功能特性

1. **显示合并后的 system prompt**
   - 展示完整的系统指令内容
   - 支持复制功能
   - 显示来源标记（默认/项目级/用户级)

   - 使用模板引擎渲染变量

2. **显示合并后的 user prompt blocks**
   - 列表显示所有用户提示区块
   - 每个区块独立显示
   - 高亮显示被覆盖的区块(紫色背景 + "已覆盖"标记)
   - 支持复制功能

   - 显示区块来源标记

3. **高亮显示覆盖的区块**
   - 磰色背景区分项目级覆盖
   - "已覆盖"标记明确标识
   - 来源标记显示(项目级/用户级)

   - 不同来源使用不同颜色标记

4. **支持复制功能**
   - 系统指令复制
   - 单个区块复制
   - 完整提示复制(包含所有内容)
   - 复制成功反馈(图标变化)

   - 使用 clipboard API

5. **显示变量列表和值**
   - 列表显示所有变量
   - 显示变量类型、描述、默认值
   - 显示当前值(如果提供)
   - 标记必填变量
   - 显示变量来源标记

   - 支持变量值编辑(示例中)

   - 实时更新预览

6. **使用模板引擎渲染预览**
   - 支持 Handlebars 语法变量替换
   - 支持条件语句 `{{#if}}`
   - 支持循环语句 `{{#each}}`
   - 可切换原始模板/渲染结果视图
   - 实时渲染更新

   - Token 估算

7. **UI 特性**
   - 可折叠面板
   - 响应式设计
   - 滚动内容
   - 工具栏
   - 警告信息显示
   - 与现有代码库风格一致(暗色主题 + 紫色强调色)
