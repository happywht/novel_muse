# 前端体验问题收集清单

## 使用说明
请在前端测试过程中，将发现的问题填写到对应模块下。每个问题包含：
- **问题描述**: 具体什么不对
- **复现步骤**: 如何触发这个问题
- **期望行为**: 应该是什么样的
- **优先级**: P0(阻塞)/P1(重要)/P2(建议)
